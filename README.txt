ANIRBAN DEY — FINAL PORTFOLIO WEBSITE

To preview locally:
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, or Firefox.

The main index.html contains the complete portfolio, including the gaming thumbnail gallery (all six designs, including Best Drills and Best Moments) and restaurant flyer gallery. The new thumbnails are included directly in the existing gallery on the main page; no separate gallery page is needed.

Additional pages:
- thumbnails.html: standalone thumbnail gallery
- restaurant-flyers.html: standalone restaurant flyer gallery
- projects/: individual gaming thumbnail project pages
- assets/: supporting image files

For publishing online, upload the full folder while preserving its directory structure.
